INSTALLATION
------------
1. Décompresser cette archive.
2. Ouvrir le dépôt GitHub : M0rdr3x/BenoitCantin
3. Add file -> Upload files.
4. Glisser TOUT le contenu décompressé à la racine du dépôt.
5. Accepter les remplacements de fichiers.
6. Commit conseillé :
   Mise à jour SINJIRA complète - Fracture, administration et demo du roman
7. Attendre le déploiement GitHub Pages.
8. Faire Ctrl+Shift+R (ou vider le cache du navigateur).
