# Icônes du portail

Les icônes SVG incluses sont des identités temporaires cohérentes et professionnelles.

Pour utiliser les icônes officielles déjà en votre possession, remplacez les fichiers en conservant les mêmes noms :

- `ere-consciences.svg`
- `lumina.svg`
- `futurax.svg`
- `jeux-creations.svg`
- `nova.svg`

Le fichier `benoit-sigil.svg` est le symbole personnel conçu pour accompagner le nom **Benoit Cantin**. Il combine le monogramme BC, des orbites et une étoile pour représenter un créateur à l'origine de plusieurs mondes.
