Confidentialité du Compte SINJIRA

Cette page décrit le comportement technique prévu du système. Elle devra être relue avant la mise en production publique comme politique officielle.

Mode invité

Le joueur peut utiliser les outils prévus pour le mode invité sans créer de sauvegarde serveur. Lorsqu’un rapport est demandé par courriel, les données nécessaires sont utilisées pour générer et transmettre le rapport sans créer automatiquement une partie dans le compte.

Compte universel

Un seul compte peut servir pour tous les jeux SINJIRA. Il peut conserver le profil, les sauvegardes de parties, les fiches, les retours, les candidatures de playtest et les droits d’accès accordés.

Photo de profil

La photo de profil est facultative. Lorsqu’elle est ajoutée, elle est recadrée et optimisée automatiquement. Elle peut être affichée dans les interfaces SINJIRA associées au compte et est servie comme image publique; n’y utilisez pas une image que vous souhaitez garder confidentielle.

Documents protégés

Les documents réservés aux comptes, joueurs approuvés ou testeurs sont conservés dans un espace privé. L’ouverture passe par un contrôle d’autorisation et un lien temporaire signé. Le fichier n’a pas d’adresse publique permanente.

Programme Contributeur

Il est facultatif et distinct des sauvegardes privées. Une partie n’est utilisée pour améliorer un jeu ou préparer de futures extensions que lorsque le joueur choisit explicitement de la partager.

Données exclues de l’analyse

Le courriel, le mot de passe, le pseudo, le code de partie et les notes privées ne sont pas destinés à la base d’analyse de gameplay.

Contrôle du joueur

Le joueur peut désactiver le Programme Contributeur, exporter les données de son compte et supprimer son compte.
