Cette page contient une illustration ou son texte ne peut pas être extrait : le PDF s'affiche automatiquement pour préserver la page originale. Glissez à gauche ou à droite pour continuer. Dès qu'une page comporte du texte lisible, la lecture adaptable reprend. Le mode PDF reste disponible manuellement.

Sur téléphone ou tablette, le mode « pages d’écran » adapte le texte à l’espace visible : glissez vers la gauche pour lire l’écran suivant ou vers la droite pour revenir. Vous pouvez également toucher brièvement la marge droite pour avancer ou la marge gauche pour reculer en mode texte paginé. Le centre du texte reste libre pour la sélection et les gestes ordinaires. À la fin de la page source, la liseuse passe à la suivante. Décochez l’option pour rétablir le défilement libre du texte. En mode PDF, le geste tourne directement les pages du document. Pour tourner les écrans au clavier, placez d’abord le focus dans la zone du livre avec Tab, puis utilisez les flèches gauche/droite ou Page précédente/suivante. Les boutons restent utilisables partout.

Glissez ou touchez les marges

En mode texte adaptable sur téléphone, vous pouvez lire un écran à la fois ou désactiver cette option pour faire défiler librement. Ajustez la présentation et écoutez le texte si vous le souhaitez. La page et l’emplacement sont enregistrés sur cet appareil uniquement si le navigateur autorise le stockage : consultez la confirmation affichée. Pour le roman intégral, la synchronisation avec votre compte dépend aussi du serveur et doit être vérifiée. Utilisez « Enregistrer ma position » pour demander une confirmation explicite. Les flèches du clavier permettent aussi de tourner les pages.
