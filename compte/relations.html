Autorisation parentale SINJIRA™

Le serveur adapte cette section au statut du compte. Un parent ou tuteur adulte peut créer ici un code à usage unique à remettre à l’enfant avant son inscription. De 11 à 13 ans, ce code est obligatoire pour créer le compte.

Protection : à 11–12 ans, le compte est créé en mode enfant supervisé. Les fonctions sociales générales et la messagerie privée restent désactivées. Une Communauté Junior séparée peut être activée explicitement ci-dessous par le parent ou tuteur. La supervision ne donne jamais un accès automatique au contenu publié ou aux messages privés.

Parent ou tuteur adulte : générez un nouveau code, puis copiez-le dans le champ « Code d’autorisation parentale » du formulaire d’inscription de l’enfant. Le code est à usage unique et expire automatiquement. La création du code exige une session AAL2 avec second facteur. Après avoir copié le code, déconnectez le compte parent avant de créer le compte de l’enfant afin que les deux identités et les deux sessions restent séparées.

Communauté Junior · 11–12 ans

La Communauté Junior est un espace texte séparé : pseudonyme automatique, aucun message privé, aucun adulte ou 13–17 ans dans le fil, aucun lien externe, aucune image et aucun commerce. L’accès doit être activé ici par un parent ou tuteur vérifié. L’activation exige une session AAL2; la désactivation reste toujours disponible pour protéger l’enfant immédiatement.

Protection sans surveillance : vous pouvez activer ou retirer l’accès et consulter un résumé d’activité, mais SINJIRA ne vous donne pas automatiquement le contenu des publications ou commentaires.

Chargement des comptes enfants 11–12 ans…

Compte enfant ou jeunesse en attente : entrez le code transmis par votre parent ou tuteur. Le code est à usage unique et doit encore être valide.

Aucune action parentale n’est requise pour ce compte.

Liens de supervision

Le tuteur doit confirmer une révocation en AAL2. Le compte enfant ou jeunesse peut quitter immédiatement son propre lien de supervision sans second facteur. Les métadonnées de contacts sont désactivées par défaut : seul le compte enfant/jeunesse peut les autoriser ou les retirer ici. Cette permission ne donne jamais accès au contenu des messages.
