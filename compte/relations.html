Supervision jeunesse

Autorisation parentale SINJIRA™

Un parent ou tuteur adulte peut créer un code à usage unique pour l’inscription d’un jeune. Pour les 12–13 ans, ce code est obligatoire. Pour les 14–17 ans, il permet de vérifier immédiatement le lien de supervision.

Protection : la supervision donne accès aux métadonnées de contact prévues par le système, jamais au contenu privé des messages.
