Autorisation parentale SINJIRA™

Le serveur adapte cette section au statut du compte. Un parent ou tuteur adulte peut créer ici un code à usage unique à remettre à l’enfant avant son inscription. De 11 à 13 ans, ce code est obligatoire pour créer le compte.

Protection : à 11–12 ans, le compte est créé en mode enfant supervisé et les fonctions sociales restent désactivées jusqu’à 13 ans. La supervision donne accès uniquement aux métadonnées de contact prévues par le système, jamais au contenu privé des messages.

Parent ou tuteur adulte : générez un nouveau code, puis copiez-le dans le champ « Code d’autorisation parentale » du formulaire d’inscription de l’enfant. Le code est à usage unique et expire automatiquement. Après avoir copié le code, déconnectez le compte parent avant de créer le compte de l’enfant afin que les deux identités et les deux sessions restent séparées.

Programme Contributeur — facultatif

Vous pourrez partager volontairement certaines données de partie pour améliorer les jeux. Cette option n’est pas activée pour les comptes enfants de 11–12 ans.

Vos données ne sont pas votre produit.

Le courriel, l’identifiant technique du compte, la naissance, la localisation privée et les relations familiales ne sont pas publiés par défaut.

Moins de 11 ans : inscription non disponible. 11–12 ans : compte enfant supervisé, autorisation parentale ou du tuteur vérifiée obligatoire et fonctions sociales désactivées. 13 ans : autorisation parentale ou du tuteur vérifiée obligatoire. 14–17 ans : compte jeunesse canadien; les fonctions sociales restent protégées jusqu’à la vérification prévue. 18+ : compte adulte. Rencontres SINJIRA™ est réservé aux 18+.

Le questionnaire de personnage est facultatif et reste accessible depuis le Registre après la création du compte.
