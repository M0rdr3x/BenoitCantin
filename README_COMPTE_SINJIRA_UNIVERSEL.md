# SINJIRA — Compte universel pour tous les jeux v2

Cette archive transforme le système de compte précédent en **un seul Compte SINJIRA**, valable pour tous les jeux présents et futurs.

Fonctions incluses :
- bibliothèque de tous les projets accessibles;
- documents approuvés;
- documents privés par niveau d'accès;
- accès joueur / testeur par projet;
- demandes d'accès;
- playtests et candidatures;
- sauvegardes de parties multi-projets;
- rapports et courriels de fin de partie;
- Programme Contributeur volontaire;
- statistiques d'amélioration;
- signaux pour les futures extensions;
- console d'administration des projets, joueurs, documents, accès et playtests.

Commencez par lire :
`INSTALLATION_COMPTE_SINJIRA_UNIVERSEL.md`
