Citation

Comment citer Projet Nova

Pour un sujet précis, citer la page ou le document source et sa date de consultation. Éviter d’attribuer au projet une position qui n’apparaît pas dans une source publique actuelle.

Formulation recommandée : « Projet Nova propose… » ou « Le document public de Projet Nova prévoit… » lorsqu’il s’agit d’une proposition.

Rectification

Demander une précision

Une demande média peut porter sur une citation, une information organisationnelle, l’état d’un document ou une demande d’entrevue. Toute réponse publique doit distinguer les faits, les propositions et les validations externes.
