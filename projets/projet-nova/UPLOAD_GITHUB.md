# Téléverser la mise à jour V4 dans GitHub

Dépôt : `M0rdr3x/BenoitCantin`

1. Décompressez `benoitcantin-mise-a-jour-v4.zip` sur votre ordinateur.
2. Dans GitHub, ouvrez le dépôt puis choisissez **Add file → Upload files**.
3. Glissez **tout le contenu situé à l'intérieur du dossier décompressé**.
4. Autorisez GitHub à remplacer les fichiers portant le même nom.
5. Utilisez le message de commit :

   `Mise à jour V4 : proportions, démo du roman et intégration complète de Projet Nova`

6. Cliquez sur **Commit changes**.
7. Attendez le nouveau déploiement dans **Actions** ou **Settings → Pages**.
8. Ouvrez `https://www.benoitcantin.com/` et rechargez avec **Ctrl+F5**.

## Ne supprimez pas la démonstration déjà présente
