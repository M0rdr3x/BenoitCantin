Fiche joueur interactive

Utilisez cette fiche pendant la partie. Elle permet d’inscrire le nom ou pseudo, le numéro de joueur, le code de partie, les cartes reçues, les rapports, les preuves, les soupçons, l’accusation finale et les notes privées.

L’identité demeure secrète jusqu’à la fin. La fiche est un PDF remplissable au format Lettre 8,5 × 11 po. En mode invité, aucune saisie n’est envoyée ou enregistrée par le site. Le joueur télécharge sa propre copie seulement s’il souhaite la conserver.
