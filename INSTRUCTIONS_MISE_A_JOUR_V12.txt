INSTALLATION GITHUB
-------------------
1. Décompresser cette archive.
2. Ouvrir le dépôt GitHub M0rdr3x/BenoitCantin.
3. Add file -> Upload files.
4. Glisser TOUT le contenu décompressé à la racine du dépôt.
5. Accepter les remplacements.
6. Commit conseillé :
   Mise à jour SINJIRA V12 - demo roman, administration et rapports
7. Attendre GitHub Pages.
8. Faire Ctrl+Shift+R.
