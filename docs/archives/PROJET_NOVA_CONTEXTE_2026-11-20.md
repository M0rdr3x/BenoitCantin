## Provenance de cette note

Cette note synthétise les éléments disponibles dans le contexte des conversations du projet « Site web perso », complétés par les références de dépôt consultées. **Ce n’est ni une exportation exhaustive de la mémoire ChatGPT ni une copie intégrale des conversations privées.** Les fichiers de travail et les preuves GitHub font autorité pour les détails techniques; les affirmations non démontrées ne doivent pas devenir des faits certifiés.

## Étendue historique de Projet Nova

- **Programme politique/citoyen Nova** : propositions, budgets, preuves juridiques et sectorielles, ressources publiques et documentation financière.
- **Nova–SINJIRA** : programme de réforme de 14 secteurs (NV-01 à NV-14), distinguant les étapes documentaires G0–G4.
- **Sondage citoyen Nova** : questionnaires, mécanismes de réception, validation légale et anti-abus, collecte non ouverte sans autorisation.
- **Boussole électorale Nova** : questionnaire multidimensionnel, comparaisons documentaires, accessibilité et neutralité.
- **Infrastructure** : pages publiques, tests, scripts, automatisations GitHub et ressources dédiées trouvés dans le dépôt au SHA archivé.

## Conservation et restauration

Le ZIP contient les **fichiers suivis par Git** sélectionnés pour Nova au commit indiqué dans son manifeste. Les noms et sous-dossiers sont conservés; l’historique d’engagements pertinents est inclus comme texte, non comme dépôt `.git`. Les **tickets GitHub, conversations privées, données d’utilisateurs, secrets d’environnement, configurations de services externes et versions non fusionnées de PR distinctes ne sont pas inclus automatiquement**.

Pour remettre en service plus tard, auditer séparément les dépendances, le schéma de base de données, les autorisations de collecte, l’accessibilité et la sécurité; **ne pas interpréter l’archive comme un environnement prêt à déployer**. Les modifications de l’accueil n’effacent aucun des fichiers archivés.
