INSTALLATION GITHUB
1. Décompresser cette archive.
2. Ouvrir le dépôt M0rdr3x/BenoitCantin.
3. Add file -> Upload files.
4. Glisser TOUT le contenu extrait à la racine du dépôt.
5. Conserver exactement l’arborescence des dossiers.
6. Accepter le remplacement des fichiers existants.
7. Message de commit recommandé :
   Remplacement complet des visuels SINJIRA et mise à jour Facebook
8. Attendre la coche verte dans GitHub Actions.
9. Faire Ctrl+F5 sur le site.
